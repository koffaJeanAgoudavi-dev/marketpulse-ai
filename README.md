🚀 MarketPulse AI - Studio Marketing IA Omnicanal

MarketPulse AI est une application SaaS (Software-as-a-Service) propulsée par l'Intelligence Artificielle. Elle permet aux solopreneurs, créateurs de contenu, agences et e-commerçants de générer des campagnes marketing omnicanales complètes (accroches virales, posts réseaux sociaux et e-mails de prospection) en moins de 30 secondes.

✨ Fonctionnalités Clés

🧠 Cœur IA & Copywriting

🎯 Accroches Virales (Hooks) : 3 formules percutantes pour stopper le scroll sur LinkedIn, Facebook, Instagram et TikTok.

📲 Posts Réseaux Sociaux : Rédaction de posts optimisés avec structure persuasive, émojis et Call-To-Action (CTA).

✉️ Cold Emails de Prospection : E-mails de vente B2B/B2C captivants prêts à l'envoi.

🌐 Sélecteur Multilingue : Génération en Français 🇫🇷, Anglais 🇬🇧, Espagnol 🇪🇸, Arabe 🇸🇦 et Swahili 🇰🇪.

⚡ Presets par Niche : Modèles pré-remplis en 1-clic pour E-commerce, Coaching/Formation, Immobilier, Restauration et Agences B2B.

💳 Monétisation & Intégrations

💳 SDK Chariow Snap (Inline Checkout) : Module de recharge de crédits via Mobile Money (Wave, Orange, MTN, Moov) et Carte Bancaire.

📊 Google Sheets Backend : Synchronisation automatique des nouveaux inscrits sans doublons via Google Apps Script.

🎁 Programme de Parrainage (+5 Crédits) : Détection automatique d'URL avec le paramètre ?ref=CODE et attribution de crédits bonus.

🔒 Modèle Freemium & Restrictions PRO : Exportation PDF, langues internationales et Analytics avancés débloqués avec le statut PRO.

🎨 Expérience Utilisateur & Productivité

📄 Exports Multi-Formats : Téléchargement des rapports de campagne aux formats .TXT et .PDF.

🌙 Mode Sombre / Mode Clair : Commutateur de thème fluide avec mémorisation de la préférence (localStorage).

📲 Aperçu Mockup Réseau Social : Rendu visuel dynamique simulant une publication LinkedIn/Instagram.

🛠️ Stack Technique

Frontend : HTML5 Semantic, Tailwind CSS (CDN), FontAwesome 6 Icons, JavaScript ES6+ Vanilla.

APIs & Cloud : Google Gemini API (Génération IA), Firebase / Firestore Realtime Database.

Paiement : Chariow Snap Widget SDK.

Export PDF : html2pdf.js.

🚀 Guide de Déploiement Rapide

Option A : Déploiement sur GitHub Pages (1-Clic)

Forkez ou clonez ce dépôt sur votre compte GitHub.

Allez dans Settings > Pages.

Dans Branch, sélectionnez main (ou master) et conservez / (root).

Cliquez sur Save. Votre application SaaS sera en ligne gratuitement à l'adresse https://<votre-pseudo>.github.io/<nom-du-repo>/ !

Option B : Déploiement sur Vercel / Netlify

Connectez votre compte Vercel/Netlify à GitHub.

Importez ce dépôt.

Conservez les paramètres par défaut et cliquez sur Deploy.

🔐 Configuration Google Sheets (Facultatif)

Pour recevoir les inscriptions de vos utilisateurs directement dans une feuille de calcul Google Sheets :

Créez un nouveau fichier sur Google Drive.

Allez dans Extensions > Apps Script.

Copiez le script d'intégration anti-doublons.

Déployez en tant qu'Application Web et remplacez l'URL GOOGLE_SHEETS_URL dans le fichier index.html.
